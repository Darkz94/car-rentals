# Cape Town Rentals — Definitive Game

Browser-based car-rental management game set around Cape Town, Stellenbosch and Franschhoek.

Play by opening `index.html` in a desktop browser. The standalone HTML includes the game runtime and its artwork; no build step is needed.

The game originally shipped as a self-contained React artifact. Its source build is bundled into the HTML. This repository stores the complete playable game and documents the vehicle/showroom visual refresh.

**Saving progress:** Use the game’s **Export JSON** option. The original game keeps its active session in memory; GitHub stores the game code, not player saves.
